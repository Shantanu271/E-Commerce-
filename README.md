# E-Commerce Website 🛍️

A responsive and interactive e-commerce website built using **HTML**, **CSS**, **Bootstrap**, and **JavaScript**. This project simulates a modern online shopping experience, featuring product listings, category navigation, and dynamic UI components. It is designed as part of a Web Development curriculum to demonstrate front-end design and user interaction.

## 📑 Problem Statement

Build a static e-commerce website that allows users to:
- Browse products by category
- View product details
- Navigate through a clean and responsive interface
- Experience basic interactivity using JavaScript

## 🌟 Features

- 🖼️ Product showcase with images and pricing
- 🧭 Navigation bar with dropdowns and links
- 📱 Responsive design using Bootstrap grid system
- 🛒 JavaScript-powered UI interactions (e.g., buttons, modals)
- 🎨 Clean and modern styling with CSS

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **JavaScript (Vanilla)**
